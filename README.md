# Rost Ready Mix | Corporate Website

Corporate website developed and deployed for
Rost Ready Mix, a concrete supplier serving
southwest Missouri.

## Project Overview

This project involved website development,
deployment, and ongoing maintenance using
GitHub and Microsoft Azure.

## Technologies & Tools

- HTML, CSS, and JavaScript
- Git and GitHub for version control
- Azure Static Web Apps for hosting
- GitHub Actions for automated deployment (CI/CD)
- Custom domain configuration and HTTPS
